# Traktor raster skin

Generated with the built-in image_gen tool using the user's selected MIDI Monitor reference.
The PNG is an immutable source atlas. SVG viewports select each sprite at runtime; moving controls remain separate layers.
All geometry is orthographic. Native atlas dimensions: 1448 × 1086.
